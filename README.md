# Implementation of Thorsten Ball's interpreter book

This repo's my hand-rolled implementation of Thorsten Ball's awesome interpreter book:
[Writing an Interpreter in Go](https://interpreterbook.com/).

Highly recommend it to anyone even remotely curious about how interpreters work.
Reading through the book and writing out the code yourself, as the author suggests, really cements how lexers, parsers,
abstract syntax trees (ASTs), and the interpreter all fit together.

Powerful stuff. Looking forward to the follow-up - [Writing a Compiler in Go](https://compilerbook.com/) - since this
repository will also serve as its foundation.
